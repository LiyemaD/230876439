Proposed Team Project: Learning Management System

Project Overview

The proposed team project is to develop an online Learning Management System designed to streamline online education. The platform allows instructors to host materials and help students track their academic progress seamlessly.

Key Core Features

  • Course Portal: A clean dashboard for student to view lectures, download slides, and track assignment deadlines.
  • Dynamic Assessment Engine: Automated quizzes power by backend scripts to deliver instant grade feedback.
  • Student Analytics: Visual progress bars showing course completion metrics.
